# Pending Suggestions

## Reproduction

- Show a visual warning when a reproduction record is a birth with an associated calf.
- Clarify in the detail view and before deletion that deleting the reproduction record does not automatically delete or update the calf animal record.
- Evaluate a more complete flow for these cases:
	- keep the calf and delete only the reproduction event,
	- delete the associated calf as well,
	- or ask for explicit confirmation about what should happen to the calf.
